# Садовый помощник

Помощник для браузерной игры **«Садовая империя»** (Molehill Empire /
Wurzelimperium, upjers). Ставит внутрь игры несколько кнопок-гномов: полить
весь сад, засеять свободные клетки, подсветить, что созрело, и выставить
товар на рынок по разумной цене.

Программа для Windows, без установки и без расширений браузера.

## Скачать

Готовый файл — на [странице выпусков][relizy]. Скачайте `Sadovyy-pomoshnik.exe`
и запустите двойным щелчком; устанавливать ничего не нужно.

Нужно, чтобы стояло приложение [upjers Home][upjers]: игрок заходит в игру
через него.

[relizy]: https://github.com/akonyaev-ru/sadovyy-pomoshnik/releases/latest
[upjers]: https://ru.upjers.com/upjers-home-games-download

## Откуда это пошло

У человека, для которого сделана эта программа, много лет стояло расширение
**CupIvan**. Осенью 2026 года оно исчезло из магазина Chrome, а исходников не
осталось нигде: ни у автора, ни в сети. Играть без него стало заметно
тяжелее — сад большой, кликать по каждой грядке долго.

Этот репозиторий — форк [CupIvan/sadowajaimperija][ivan], чтобы происхождение
замысла было видно. **Кода оттуда здесь нет ни строки:** в том репозитории
лежит userscript 5.2 от 2012 года под Tampermonkey, а здесь программа на
Python, которая доставляет свой JavaScript в игру по отладочному протоколу
браузера. Общее — идея и уважение к тому, кто её придумал.

[ivan]: https://github.com/CupIvan/sadowajaimperija

## Что умеет

| гном | что делает |
|---|---|
| лейка | поливает всё, что игра разрешает полить — в обычном и водном саду |
| посадочный автомат | засеивает свободные клетки выбранными на полке семенами |
| фонарь | подсвечивает сад: синее — полить, зелёное — созрело, чёрное — пусто |
| рыночная площадь | открывает торговую палатку и заполняет форму продажи |

Плюс столбик сбоку: переход в любой купленный сад, рынок, карта города,
выращивание грибов и улиточные бега — те места, которые у игрока открыты.
И выгодность предложения прямо в листке попрошайки: насколько он даёт больше
или меньше, чем товар стоит по оценке самой игры.

## Правила, на которых всё держится

Они не украшение — каждое куплено ошибкой, и в коде есть проверки, которые не
дают их откатить.

1. **Ничего не происходит без нажатия.** Программа не поливает по таймеру, не
   ходит на сервер сама и не «играет» за человека. Она делает ровно то, что
   сделал бы он руками, и только когда он нажал.
2. **Опасные ветви игры отсекаются ДО вызова.** У игры есть действия, которые
   молча тратят деньги (ускорение роста, снос). Однажды помощник открыл такое
   окно на живом аккаунте — с тех пор всё, что не обычный овощ, отсеивается
   заранее.
3. **Своих окон и таблиц не рисуем.** Помощник вплетается в интерфейс игры:
   заполняет её формы, подсказывает её же средствами. Панель рядом с игрой —
   это чужеродно, и от такого здесь отказались трижды.
4. **Комиссию рынка человек видит сам.** Продажа идёт в два шага, как в игре:
   помощник заполняет, а «предложить» и «O.K.» нажимает игрок. Молча тратить
   чужие деньги нельзя.

## Чего он не делает

- **Не добывает коины.** Это премиальная валюта за настоящие деньги. Всё, что
  обещает её «накрутку», — либо обман, либо дыра на сервере.
- **Не собирает урожай.** У игры для этого есть свой гном-жнец, дублировать
  его незачем.
- **Не обходит рынок в фоне.** Цену одного товара спрашивает одним запросом и
  только когда на этот товар нажали.

## Как устроено

```
Садовый помощник.exe
   ├─ находит приложение upjers Home (отдельный Chrome — только по `--target browser`)
   ├─ подключается к нему по отладочному протоколу браузера
   ├─ вставляет src/panel.js в страницу игры — и после каждой перезагрузки
   └─ заходит в «Садовую империю» сам, не дожидаясь выбора игры
```

Почему программа, а не расширение: игрок заходит в игру только через
приложение **upjers Home**, а это Electron — магазина расширений там нет.
Отладочный протокол работает и в нём.

Устройство самой игры разобрано **по её собственному исходнику**, а не по
догадкам: `gardenjs`, очередь действий, правила полива, рынок в трёх
вложенных кадрах, коридор допустимых цен. Всё это записано в
[`docs/game-api.md`](docs/game-api.md) — самая полезная часть репозитория для
того, кто захочет сделать своё.

## Если что-то не так

Программа пишет журнал: нажмите `Win`+`R`, вставьте
`%LOCALAPPDATA%\SadovyPomoshnik` и нажмите Enter — откроется папка. В ней
`помощник.log` (последний запуск) и `помощник.1.log` (предыдущий). В журнале
видно, где искали приложение, куда подключились и что панель сама о себе
сообщает: появилась ли, спряталась ли и почему, сколько садов увидела.

Если помощник не находит приложение сам, путь можно назвать явно:
`"Садовый помощник.exe" --app "C:\…\upjers Home.exe"`.

## Запуск и сборка

```bash
python -m pip install -r requirements.txt
python run.py                      # запустить из исходников
python tools/build.py              # собрать .exe
python -m pytest -q                # проверки на подделке игры
python tools/check_exe.py dist/*   # проверки собранного файла
```

Проверок около восьмидесяти, и они идут не «на моках»: `tools/stand-game.html`
повторяет поведение настоящей игры вплоть до неудобного — очередь с порогом на
шесть действий, очистка полей формы, пустое поле как «весь запас». Это не
придирчивость: пять раз подделка оказывалась ДОБРЕЕ игры, и проверка зеленела
на коде, который живьём не работал.

## Чего нет в репозитории

Папка `reference/` не публикуется. В ней лежат исходники самой игры (upjers) и
код других авторов — они нужны для работы, но прав распространять их нет.
Разбор опубликован своими словами в `docs/game-api.md`.
